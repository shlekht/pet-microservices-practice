Личная практика микросервисной архитектуры на FastAPI.

Архитектура внутри самих сервисов намеренна упрощена. БД одна, но таблицы независимы (имитация). 

Фокус на понимание и практику межсервисных взаимодействий.
___
OrderService создаёт заказ, отправляет POST запрос через httpx в PaymentService.

PaymentService имитирует оплату (asyncio.sleep) и отправляет ивент в RabbitMQ (payment succeeded)
OrderService получает ивент и обновляет статус заказа в БД.

Для создания заказа используется текущий пользователь, который достаётся из токена в Authorization заголовке.

AuthService выдаёт JWT токен, RSA256 алгоритм, OrderService декодирует и валидирует токен публичным ключом, получает оттуда id пользователя.

Docker Compose для поднятия RabbitMQ.
